# compact-notify

При запуске сжатия контекста (ручного `/compact` или автоматического) пишет в чат «Стиснення контексту запущено…» и показывает уведомление Windows. Сжатие идёт до минуты, а без мода в это время не видно, что оно уже началось.

Только Windows: хук запускает `powershell.exe`.

## Установка

```text
/plugin install compact-notify --marketplace Ven1dy/Claude-context-meter-plugin
```
