# handoff

Когда контекст разросся и качество ответов начинает падать, мод предлагает передать работу в чистую сессию. Агент пишет handoff-документ (цель, что сделано, что проверено, решения и запреты, тупики, состояние, следующий шаг), мод очищает сессию и сам отправляет новому агенту промпт «прочитай документ и продолжи».

- Команда `/handoff [сообщение]` запускает передачу вручную. Сообщение уйдёт новому агенту вместе с промптом.
- Документ сохраняется в `<папка проекта>/.claude/handoffs/handoff-ГГГГ-ММ-ДД-ЧЧММ.md`.
- Предложение появляется строкой над полем ввода в три уровня настойчивости.

## Настройка

Пороги в токенах, отдельно для больших окон (от 500k) и коротких (до 500k): `softTokens`, `firmTokens`, `lastTokens` и такие же с суффиксом `Small`. По умолчанию 350k, 600k, 800k и 100k, 150k, 170k.

## Установка

```text
/plugin install handoff --marketplace Ven1dy/Claude-context-meter-plugin
```
