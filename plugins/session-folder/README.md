# session-folder

Подпись в подвале Claude Code: папка сессии (путь от домашней папки, например `~/work/site`) и ветка git. Если основная рабочая папка сессии сменилась после `cd`, подпись выделяется предупреждающим цветом: «папка сменилась: X (была Y)». Это защита от ситуации, когда агент молча работает не в том проекте.

Команд нет, настраивать нечего.

## Установка

```text
/plugin install session-folder --marketplace Ven1dy/Claude-context-meter-plugin
```

Или весь пак одной командой: см. [README репозитория](../../README.md).
