# blast-radius

Перед разрушительной командой Bash (`rm -rf`, `git reset --hard`, `git clean`, force push, миграции баз) мод останавливает вызов и показывает над полем ввода карточку: что именно пропадёт (сколько файлов и мегабайт, какие изменения не закоммичены, какие миграции применятся). Кнопки: Выполнить, Отложить, Отмена.

Если не ответить за 90 секунд или нажать Отложить, команда попадает в общую очередь удалений, агент получает отказ и не зависает. Позже ты выполняешь или отклоняешь её в панели `/deletions`, мод запускает команду сам и сообщает агенту результат.

- Команда `/deletions` открывает очередь.
- Очередь общая для всех сессий и лежит в `~/.claude/blast-radius/queue.json`.

На Windows мод ищет Git Bash в `C:/Program Files/Git/usr/bin`, иначе берёт `bash` из PATH. Нужен установленный Git for Windows.

Основан на моде blast-radius из anthropics/claude-code-playground (Apache-2.0), переработан. Текст лицензии в файле `LICENSE`.

Настраивать нечего.

На macOS оценка удаляемого идёт запасным путём для BSD-версии `find` (без GNU `-printf` и `-newermt`); на реальном macOS он не проверялся.
