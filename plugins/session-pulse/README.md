# session-pulse

Полоса над полем ввода с двумя счётчиками: сколько осталось жить кэшу промпта основного диалога и сколько израсходовано лимитов (5 часов и неделя). Пока кэш тёплый, ответы быстрее и дешевле. За несколько минут до остывания появляются кнопки:

- Подогреть: отправляет короткий служебный запрос, кэш живёт дальше.
- Авто: сам подогревает кэш выбранное число часов.
- Сжать: сжимает контекст.
- Где мы: коротко пересказывает, над чем шла работа (запрос к модели Haiku).
- Скрыть.

Команд нет.

## Настройка

Параметр `ttlMinutes` (время жизни кэша, минут). По умолчанию 5, это стандартное значение. Если у твоего аккаунта часовой кэш, поставь 60. Не уверен, оставь 5.

Подогрев и пересказ делают реальные запросы к модели и тратят лимит.
