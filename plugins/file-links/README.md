# file-links

Делает пути к файлам в ответах агента кликабельными. Путь в обратных кавычках (`src/app.ts`) или битую markdown-ссылку мод превращает в ссылку относительно рабочей папки сессии. Меняется только отрисовка, сохранённое сообщение остаётся прежним. Если файл лежит вне папок сессии, мод просит Claude Desktop добавить его папку (один раз за сессию).

Рассчитан на файловую панель Claude Desktop.

## Настройка

Параметр `linkStyle`:

- `percent` (по умолчанию): пробелы и скобки в пути кодируются как `%20`, `%28`, `%29`. Работает в панели Desktop.
- `angle`: путь в угловых скобках. Панель Desktop их не понимает.

Команд нет.

## Установка

```text
/plugin install file-links --marketplace Ven1dy/Claude-context-meter-plugin
```
