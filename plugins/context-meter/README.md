# context-meter

Полоса над полем ввода: сколько процентов контекста занято (`47% 94K / 200K`) и сколько добавило последнее сообщение (`+16K за ход`).

- Нажатие на проценты открывает `/context`.
- Нажатие на «за ход · история» открывает панель рядом с чатом. В ней разбивка по категориям (системный промпт, инструменты, переписка) и таблица прироста по каждому сообщению. Модель панель не видит, токены на неё не тратятся.
- После сжатия в чате появляется строка «Сессия сжата: было 130K → стало 70K, сэкономлено 60K».
- При заполнении 30% мод один раз предупреждает и играет звук. После сжатия предупреждение снова взводится.
- Кнопки `/compact` и `/clear`. Перед очисткой мод спрашивает подтверждение.
- Команда `/context-history` открывает панель истории.

Настраивать нечего.

## Установка

```text
/plugin install context-meter --marketplace Ven1dy/Claude-context-meter-plugin
```

Или весь пак одной командой: см. [README репозитория](../../README.md).
